## BindingSourceSchemas

```ts
interface BindingSourceSchemas
```

The schemas a field picker draws from when authoring an injection or an adapter:
the run's `output` and `input` fields (the state's fields ride each
`BindingStateOption`). Absent roots offer no picked field — the author uses
a literal or a jq expression instead.

**Properties**

| Property | Type | Description |
|---|---|---|
| `error?` | `string` | The tool-schema fetch failed — the field control shows a note but stays usable. |
| `input?` | `readonly SchemaFieldPath[]` | — |
| `loading?` | `boolean` | The tool-schema fetch that feeds the pickers is in flight. |
| `output?` | `readonly SchemaFieldPath[]` | — |

**Related:** [SchemaFieldPath](/reference/studio-sdk/utilities#schemafieldpath)

## FeatureDisabled

```ts
function FeatureDisabled(props: FeatureDisabledProps): ReactNode
```

The muted, honest OFF state for a feature whose store this deployment has not
configured. A `role="status"` EmptyState (never the loud alert ErrorState): the
feature is not broken, it is simply off, and the copy shows the server's own
remediation message.

**Props**

| Prop | Type | Description |
|---|---|---|
| `feature` | `string` | The human name of the OFF feature, e.g. `Interactions`. |
| `message` | `string` | The server's own remediation line, shown verbatim (never a client-composed string). |

## resolveCallName

```ts
function resolveCallName(
  callName: string,
  catalog: readonly BindingTemplateOption[],
): string | null
```

Resolve a jq call name (`enc(template)__name`, or a bare `name`) back to the catalog
ref, driven by the catalog — never by string splitting, since a jq name may carry its
own `__` past the template boundary and `enc` maps `-`→`_`. Under the template-slug
invariant (no consecutive/trailing hyphens ⇒ `enc(template)` has no `__` and no
trailing `_`) the FIRST `__` is the one true boundary, so the longest encoded-template
prefix whose remainder is a jq the template declares is the unique qualified match;
failing that, a bare name a single template declares. `null` when nothing claims it.
