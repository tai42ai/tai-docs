The ``backend_*`` tool surface every backend offers: its names, its refusal and its not-ready text.

The kit registers the surface once over a backend's seams: the ten schedule tools over its
`ScheduleStore`
(`tai42_kit.backend.schedule_tools`) and the twelve task and worker tools over its
`WorkerInspection`
(`tai42_kit.backend.inspection_tools`). A tool the backend cannot serve is still
registered, and raises `UnsupportedBackendTool` when called.

Each tool is registered through `backend_tool` as a tool of the backend package that
registers the surface, not of the kit module that builds it.

## backend_tool

`tai42_kit.backend.tool_surface.backend_tool`

```python
backend_tool(module: str) -> Callable[[_Tool], _Tool]
```

The decorator registering one ``backend_*`` tool, tagged ``backend``, as a tool of ``module``.

``module`` is the backend package registering the surface. The host attributes a tool to the
module its function names (``__module__``) and admits the tools of the package the manifest's
``backend_module`` names, so the kit-built function is named into that package before it is
registered. The builder modules keep their annotations evaluated, so a tool's annotations
resolve whichever module it names.

The ten schedule tools every scheduling backend offers, built once over its schedule store.

`register_schedule_tools` registers them over a backend's
`ScheduleStore`: list, get, update, enable, disable,
run now, exists, delete, and the export/import pair. Each tool has one argument list and one
reply on every backend; a status reply is ``{"status": ..., "name": name}``. What a store cannot
represent is refused here, by its declared capabilities: a disabled schedule on a store that holds
none, a relative interval on a store that honours none.

The twelve task and worker tools every backend offers, built once over its worker inspection.

`BackendInspection` is the base a backend's
`WorkerInspection` builds on: each view it does not
override refuses with `UnsupportedBackendTool`, and its
capabilities default to ``False``. `register_inspection_tools` registers the tools over it,
each with one argument list on every backend; a ``worker_name`` the backend cannot address, or a
``terminate`` it cannot honour, is refused here before the view is reached.
