Checkpoint savers for LLM graph state: the provider registry, the per-loop registry, and the retention seams.

A checkpoint store is a registration of `CheckpointProvider` (its name, its facts, the hooks the
kit applies its features through); the kit's built-in stores register at this package's import. The
owner-declared thread retention, the finished-thread ledger calls, the live-thread filter registry and
the pieces a store's registration builds on (the shared-value chunker and resolver, the value store
and ledger protocols, the msgpack value encoding) are exported here.

## CheckpointSerializationError

`tai42_kit.llm.checkpoint.checkpoint.CheckpointSerializationError`

```python
class CheckpointSerializationError(Exception)
```

A checkpoint value could not be stored faithfully, or a stored value could not be read back.

The guard converts ormsgpack's ``MsgpackEncodeError`` into this typed error so a value
the serializer cannot encode fails loudly — never a silent pickle fallback, never an
opaque engine crash. The checkpoint guard owns the storage integer range: an integer
outside the native msgpack range ``[-2**63, 2**64-1]`` has no encoding, and the message
NAMES the offending path. A store's codec raises it for a value it cannot store
faithfully and for a stored value it cannot decode.

## ThreadRetention

`tai42_kit.llm.checkpoint.retention.ThreadRetention`

```python
class ThreadRetention
```

How long a checkpoint thread is kept, in minutes, bounded by the platform's values.

``waiting_minutes``: after its last write, while its owner may still continue it.
``finished_minutes``: after its owner marked it finished.

Every value is checked when it is built, so every seam that takes one (the saver views, the
finished-thread ledger, the park horizon) holds the platform's ceiling. Raises
`ThreadRetentionError` for a value that is not positive, a value above the platform's
for its horizon, or a finished longer than the waiting.

**Attributes**

| Attribute | Type |
|---|---|
| `waiting_minutes` | `int` |
| `finished_minutes` | `int` |

`tai42_kit.llm.checkpoint.providers.checkpoint_park_horizon`

```python
checkpoint_park_horizon(provider: str, retention: ThreadRetention | None = None) -> timedelta | None
```

How long a parked run's checkpoint is kept on ``provider``; ``None`` when the store does not outlive the process.

On a durable provider a parked thread's last write is its park checkpoint, and the thread is kept its
waiting retention after it — the owner's declared one, else the platform's — so a park may wait at
most that long.

## latest_park_deadline

`tai42_kit.llm.checkpoint.providers.latest_park_deadline`

```python
latest_park_deadline(provider: str, retention: ThreadRetention | None = None) -> datetime | None
```

The latest ask deadline a park taken now on ``provider`` can serve; ``None`` on a store dying with the process.

The park's checkpoint is written at or after now and kept `checkpoint_park_horizon` after
it. The platform may deliver an ask's answer or expiry up to its redelivery horizon after the
deadline, so the latest deadline is the checkpoint's earliest expiry less that horizon: a
delivery at any moment the platform still holds the ask finds the checkpoint.

## mark_threads_finished

```python
    *,
    retention: ThreadRetention | None = None,
    provider: str | None = None,
    conn_string: str | None = None,

```

Mark ``thread_ids`` finished now, in the ledger of the store that holds them.

propagates.
