Checkpoint savers for LLM graph state, their per-loop registry, and the retention seams every thread owner uses.

The provider table, the owner-declared thread retention, the finished-thread ledger calls and the
live-thread filter registry are exported here; the savers, codecs and store-format gate live in their own modules.

## FinishedThreadLedger

`tai42_kit.llm.checkpoint.ledger.FinishedThreadLedger`

```python
class FinishedThreadLedger(Protocol)
```

The per-thread retention record of one checkpoint store.

It holds the finished marks and their due times, the declared waiting retentions, and lists the
threads past their waiting horizon. Every method that takes thread ids takes any sequence; an
empty one changes nothing, on every provider.

## ThreadRetention

`tai42_kit.llm.checkpoint.retention.ThreadRetention`

```python
class ThreadRetention
```

How long a checkpoint thread is kept, in minutes, bounded by the platform's values.

``waiting_minutes``: after its last write, while its owner may still continue it.
``finished_minutes``: after its owner marked it finished.

Every value is checked when it is built, so every seam that takes one (the saver views, the
finished-thread ledger, the park horizon) holds the platform's ceiling. Raises
`ThreadRetentionError` for a value that is not positive, a value above the platform's
for its horizon, or a finished longer than the waiting.

**Attributes**

| Attribute | Type |
|---|---|
| `waiting_minutes` | `int` |
| `finished_minutes` | `int` |

## mark_threads_finished

`tai42_kit.llm.checkpoint.ledger.mark_threads_finished`

```python
async mark_threads_finished(
    thread_ids: Sequence[str],
    *,
    retention: ThreadRetention | None = None,
    provider: str | None = None,
    conn_string: str | None = None,
) -> None
```

Mark ``thread_ids`` finished now, in the ledger of the store that holds them.

They become deletable their finished retention after now: ``retention``'s (the owner's
declaration, see `resolve_retention`), else the
platform's. ``provider`` and ``conn_string`` resolve independently: ``None`` is the deployment's
configured checkpoint provider, respectively its configured connection string. A caller that
checkpoints on a per-run provider passes it. An empty sequence is a no-op; a store error
propagates.

## resolve_retention

`tai42_kit.llm.checkpoint.retention.resolve_retention`

```python
resolve_retention(*, waiting_minutes: int | None = None, finished_minutes: int | None = None) -> ThreadRetention
```

Resolve an owner's declaration against the platform's values.

An unset waiting is the platform's; an unset finished is the platform's finished capped at the
resolved waiting (a finished thread is never kept longer than a waiting one). The resolved
value is bounded where it is built (`ThreadRetention`), which raises
`ThreadRetentionError` for a declaration out of bounds.
