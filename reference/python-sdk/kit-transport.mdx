MCP client transports over a unix-domain socket + the transport selector.

The UDS transports implement the contract ``Transport`` Protocol; ``get_mcp_transport``
picks between them, fastmcp's remote transports for URL servers, or fastmcp's stdio
transport for command servers, whose bare command ``resolve_stdio_command`` finds on a
``PATH`` or among the commands the declared `StdioLaunch` provider exposes, and
whose child's stderr is this process's standard error descriptor (see
`tai42_kit.transport.stdio_launch`).

## get_mcp_transport

`tai42_kit.transport.utils.get_mcp_transport`

```python
get_mcp_transport(config: TaiMCPConfig, *, uds_protocol: str = 'http') -> HTTPUDSTransport | SSEUDSTransport | StreamableHttpTransport | SSETransport | StdioTransport
```

Build the fastmcp transport for one MCP server config.

A UDS server connects over a unix socket; ``uds_protocol`` selects the MCP
wire protocol carried on it (``http`` = streamable-http, ``sse`` = SSE) — the
caller (which owns the runtime/CLI) supplies it, so it arrives unvalidated and
any other value raises. A URL server gets fastmcp's SSE or streamable-http
transport, chosen by fastmcp's own URL inference, carrying only the config's
headers and built on `mcp_http_client`; it ignores ``uds_protocol``. A
command server gets fastmcp's stdio transport running the executable
`resolve_stdio_command` finds for it (a bare
name with no executable match raises) with the config's ``args`` and its ``env``
exactly as declared; the child's stderr is this process's standard error descriptor
(`stdio_child_stderr`). A config that sets
none of ``uds``, ``url`` and ``command`` raises `ValueError` naming the server.

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `config` | `TaiMCPConfig` | — | — |
| `uds_protocol` | `str` | `'http'` | — |


## resolve_stdio_command

`tai42_kit.transport.stdio_launch.resolve_stdio_command`

```python
resolve_stdio_command(command: str, env: Mapping[str, str]) -> str
```

Return the executable a stdio server launched as ``command`` with ``env`` runs.

A command with a directory part is returned unchanged. A bare name resolves to the
first executable match on ``env``'s ``PATH`` when it sets one, then the command of that
name the declared provider exposes now, then on this process's ``PATH`` when ``env``
sets none. With no executable match, raises `PermissionError` when a match is
not an executable file, else `FileNotFoundError`, naming the ``PATH`` searched
and the exposed command names.

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `command` | `str` | — | — |
| `env` | `Mapping[str, str]` | — | — |
