MCP client transports over a unix-domain socket + the transport selector.

The UDS transports implement the contract ``Transport`` Protocol; ``get_mcp_transport``
picks between them, fastmcp's remote transports for URL servers, or a plain
dict-config for command servers, launched as the declared `StdioLaunch` says:
``resolve_stdio_command`` finds the command and the install location it is in, and
``stdio_child_env`` composes the child's ``env`` with that location's import directories
(see `tai42_kit.transport.stdio_launch`).

## get_mcp_transport

`tai42_kit.transport.utils.get_mcp_transport`

```python
get_mcp_transport(config: TaiMCPConfig, *, uds_protocol: str = 'http') -> HTTPUDSTransport | SSEUDSTransport | StreamableHttpTransport | SSETransport | dict[str, Any]
```

Build the fastmcp transport for one MCP server config.

A UDS server connects over a unix socket; ``uds_protocol`` selects the MCP
wire protocol carried on it (``http`` = streamable-http, ``sse`` = SSE) — the
caller (which owns the runtime/CLI) supplies it, so it arrives unvalidated and
any other value raises. A URL server gets fastmcp's SSE or streamable-http
transport, chosen by fastmcp's own URL inference, carrying only the config's
headers and built on `mcp_http_client`; it ignores ``uds_protocol``. A
command server returns a plain fastmcp dict-config whose ``command`` is the
executable `resolve_stdio_command` finds
for it (a bare name with no executable match raises) and whose ``env`` is the
config's, carrying the import directories of the install location the command was
found in, when that location declares any
(`stdio_child_env`).

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `config` | `TaiMCPConfig` | — | — |
| `uds_protocol` | `str` | `'http'` | — |


## resolve_stdio_command

`tai42_kit.transport.stdio_launch.resolve_stdio_command`

```python
resolve_stdio_command(command: str, env: Mapping[str, str]) -> ResolvedStdioCommand
```

Return what a stdio server launched as ``command`` with ``env`` runs.

A command with a directory part is returned unchanged, with no import directories. A
bare name resolves to the first executable match on ``env``'s ``PATH`` when it sets
one, then in the declared locations' scripts directories, then on this process's
``PATH`` when ``env`` sets none; a match in a location carries that location's import
directories, a match on a ``PATH`` none. With no executable match, raises
`PermissionError` when a file of that name exists but is not executable, else
`FileNotFoundError`, naming every directory searched.

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `command` | `str` | — | — |
| `env` | `Mapping[str, str]` | — | — |


## stdio_child_env

`tai42_kit.transport.stdio_launch.stdio_child_env`

```python
stdio_child_env(env: Mapping[str, str], import_dirs: Sequence[str]) -> dict[str, str]
```

Return the ``env`` a stdio server child declared with ``env`` is launched with.

A copy of ``env``. With ``import_dirs``, its ``PYTHONPATH`` is the server's own
``PYTHONPATH`` entries (empty entries dropped), then ``import_dirs``, joined with
`os.pathsep`; with none, the copy is unchanged. Every other key passes through
as given.

**Parameters**

| Parameter | Type | Default | Description |
|---|---|---|---|
| `env` | `Mapping[str, str]` | — | — |
| `import_dirs` | `Sequence[str]` | — | — |
