``tai42_kit.logging``).

## changes_only_by_respawn

`tai42_kit.settings.registry.changes_only_by_respawn`

```python
changes_only_by_respawn(cls: type[BaseSettings]) -> bool
```

Whether every value of the registered settings group ``cls`` changes only by a process respawn or restart.

True when ``cls`` is registered and every field's reload class is ``recycle`` or
``excluded``; a field that references a nested group is judged by that group's own
registered fields, recursively. False for an unregistered class (a plain
``BaseSettings``, a ``registry_exclude`` base, a class with no fields), for a nested
group that is unregistered or references back into the groups being judged, and
for any ``hot`` field.

## env_file_reads_suspended

`tai42_kit.settings.env_file.env_file_reads_suspended`

```python
env_file_reads_suspended(path: str | os.PathLike[str]) -> Iterator[None]
```

Read the env file at ``path`` in no settings construction inside the block.

``path`` is resolved on entry (a relative path against the working directory, symlinks
followed), and a settings class whose env file resolves to the same file reads no env
file inside the block; an env file at any other path is still read. Blocks nest, each
adding its path. The state is held in a context variable: a task created inside the
block copies the context and so skips the file too, while a thread started with
``threading.Thread`` starts from an empty context and reads it, unless the interpreter
makes threads inherit the context (``sys.flags.thread_inherit_context``).

## settings_cache

`tai42_kit.settings.cache_registry.settings_cache`

```python
settings_cache(fn: F) -> F
```

Cache a zero-arg settings accessor, register it for reset, and epoch-stamp it.

Stamping happens on the CONSTRUCTION path (cache miss), so the stamp records
the epoch the instance was born under; a cached hit returns the same stamped
instance, and a reset clears the cache so the next call rebuilds and re-stamps
under the then-current epoch.

One accessor exists per qualified name: decorating a function whose name is already
registered (a module re-import) re-binds that accessor to the new function, clears its
cache and returns the same wrapper.

## settings_field_env_value

`tai42_kit.settings.env_names.settings_field_env_value`

```python
settings_field_env_value(env: Mapping[str, str], group: str, field: SettingsFieldInfo) -> str | None
```

The value ``env`` gives the scalar field ``field`` of the settings group ``group``; ``None`` when none.

``group`` is the group's qualified name. Read as the settings layer reads it. In precedence
order, highest first: the registered groups that nest ``group`` (outermost first), each
through its JSON name with its delimited names merged over it; then the field's own names
(`_own_layers`). Objects from several of these merge key by key, as the settings layer
combines them. Empty values are absent. The value is in env form: a string read from one
name as it is, anything else JSON-encoded. A name whose value must be JSON and is not raises,

## sweep_stale_settings

`tai42_kit.settings.cache_registry.sweep_stale_settings`

```python
sweep_stale_settings(retired_epoch: int) -> list[StaleHolder]
```

Report every settings instance stamped with ``retired_epoch`` that something still holds.

The roster holds only settings whose values can change within the process, so
the sweep judges only those. Walks the roster for instances whose stamp is the retired epoch and are still
alive. When any is found, cyclic garbage is collected first, so an instance
that only unreachable objects keep (the finished frame of a cancelled task
awaiting collection) is freed rather than reported. Each instance still alive
after that is reachable, which is a stale-config leak: it is logged at ERROR
naming its holders (a referrer's type, or the function and ``file:line`` of a
frame or coroutine that keeps it) and returned, so a probe/e2e can assert zero.
Nothing is dropped.

|---|---|---|---|
| `retired_epoch` | `int` | — | — |

## unknown_owned_env_keys

`tai42_kit.settings.owned_prefix.unknown_owned_env_keys`

```python
unknown_owned_env_keys(keys: Iterable[str], *, service_link_env: Mapping[str, str] | None = None) -> list[tuple[str, str]]
```

``(key, prefix)`` for each key under an owned prefix that no registered group accepts, sorted by key.

Comparison is upper-cased; the accepted set is the union of ``accepted_env_vars`` of every
registered group (any prefix), so an alias declared elsewhere is accepted. A key under
several owned prefixes is reported with the longest. With ``service_link_env`` (the
process environment), an unaccepted key for which
``is_kubernetes_service_link(key, kubernetes_service_link_names(service_link_env))`` holds
is not reported: the container runtime injects a Service's link family into every pod of
its namespace, and a Service named like an owned prefix yields names under it. A lone
``<NAME>_PORT`` or ``<NAME>_SERVICE_HOST``, or any key outside a Kubernetes pod, is
reported like any unknown name.
