Manage checkpoint retention.

```console
$ tai checkpoints [OPTIONS] COMMAND [ARGS]...
```

## `tai checkpoints sweep`

Delete checkpoint threads past their retention horizon (finished, then waiting).

Example: `tai checkpoints sweep`

```console
$ tai checkpoints sweep [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
