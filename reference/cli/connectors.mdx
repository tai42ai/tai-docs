Manage connector providers and connections.

```console
$ tai connectors [OPTIONS] COMMAND [ARGS]...
```

## `tai connectors add-server`

Add an MCP server that signs in with OAuth as a connector provider.

Example: `tai connectors add-server https://mcp.example.com/mcp --name "Team tools"`

```console
$ tai connectors add-server [OPTIONS] {url}
```

| Argument | Description |
| --- | --- |
| `url` | The address of the MCP server to add. _(required)_ |

| Option | Description |
| --- | --- |
| `--id` `&lt;str&gt;` | The provider id (default: suggested from the host). |
| `--name` `&lt;str&gt;` | The display name. |
| `--description` `&lt;str&gt;` | A description. |
| `--icon-url` `&lt;str&gt;` | An https URL of an icon. |
| `--category` `&lt;str&gt;` | The catalog category (default: other). |
| `--scope` `&lt;str&gt;` | A scope to request (repeatable; default: what the server lists). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai connectors connect`

Start a connection flow; prints the authorize URL (or the created connection).

Example: `tai connectors connect google --alias work --sub-service gmail`

```console
$ tai connectors connect [OPTIONS] {provider}
```

| Argument | Description |
| --- | --- |
| `provider` | Provider id. _(required)_ |

| Option | Description |
| --- | --- |
| `--alias` `&lt;str&gt;` | A unique alias for the new connection. _(required)_ |
| `--sub-service` `&lt;str&gt;` | An enabled sub-service (repeatable). _(required)_ |
| `--config` `&lt;str&gt;` | Provider config values as a JSON object. |
| `--config-file` `&lt;str&gt;` | Read the provider config values from a file, or from stdin when the path is '-', which keeps provider secrets off the command line (a value on argv leaks via ps and shell history). Mutually exclusive with --config. |
| `--return-url` `&lt;str&gt;` | Where to return after the flow completes (omitted: the deployment's connectors page). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai connectors reencrypt-tokens`

Re-encrypt every stored token and client credential under the current CONNECTORS_KEK.

Run after rotating CONNECTORS_KEK (old key moved to CONNECTORS_KEK_PREVIOUS) to
converge every connection token blob and every stored OAuth client blob onto the
new key so the previous key can be retired.

Example: `tai connectors reencrypt-tokens`

```console
$ tai connectors reencrypt-tokens [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai connectors set-client`

Set the client credentials of an app registered by hand for a discovered provider.

Example: `tai connectors set-client mcp_example_com --client-id app --client-secret-file - --issuer URL`

```console
$ tai connectors set-client [OPTIONS] {provider_id}
```

| Argument | Description |
| --- | --- |
| `provider_id` | Provider id. _(required)_ |

| Option | Description |
| --- | --- |
| `--client-id` `&lt;str&gt;` | The client id of the app registered by hand. _(required)_ |
| `--client-secret-file` `&lt;str&gt;` | Read the client secret from a file, or from stdin when the path is '-' (never an argument: a value on argv leaks via ps and shell history). Leave out for an app without a secret. |
| `--auth-method` `&lt;str&gt;` | client_secret_post, client_secret_basic or none (default: chosen from the sign-in service). |
| `--issuer` `&lt;str&gt;` | The sign-in service the app belongs to; the secret is sent to no other. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
