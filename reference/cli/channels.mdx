Inspect the registered delivery channels.

```console
$ tai channels [OPTIONS] COMMAND [ARGS]...
```

## `tai channels list`

List the registered channel names.

Example: `tai channels list`

```console
$ tai channels list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
