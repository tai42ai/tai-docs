Browse the global tool-extension catalog.

```console
$ tai extensions [OPTIONS] COMMAND [ARGS]...
```

## `tai extensions list`

List every registered extension in the global catalog.

Example: `tai extensions list`

```console
$ tai extensions list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
