Register and inspect webhook hooks.

```console
$ tai hooks [OPTIONS] COMMAND [ARGS]...
```

## `tai hooks create-trigger-link`

Mint a trigger link — a PUBLIC URL that fires the topic's hooks.

Exactly ONE of `--ttl SECONDS` or `--permanent` is required (expiry is an
explicit choice — there is no default). The token is shown ONCE, in the printed
absolute URL; the link is MULTI-use and revocable by name (`tai hooks
delete-trigger-link NAME`). Regenerate = revoke + create.

Example: `tai hooks create-trigger-link orders --ttl 3600 --params '&#123;"priority":"high"&#125;'`

```console
$ tai hooks create-trigger-link [OPTIONS] TOPIC
```

| Argument | Description |
| --- | --- |
| `TOPIC` | The hook topic the link fires. _(required)_ |

| Option | Description |
| --- | --- |
| `--name` `TEXT` | Link name (the revocation handle); a unique name is generated when omitted. |
| `--ttl` `INTEGER` | Link lifetime in seconds (a timed link). |
| `--permanent` | Mint a link that never expires. _(default: `False`)_ |
| `--params` `TEXT` | Per-link tool_kwargs as a JSON object, merged last at each fire. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai hooks delete-trigger-link`

Revoke a trigger link by name (immediate and durable — a restored backup
cannot re-arm it).

Example: `tai hooks delete-trigger-link my-wall-qr`

```console
$ tai hooks delete-trigger-link [OPTIONS] NAME
```

| --- | --- |

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai hooks list`

List registered hooks (and the per-topic verifier bindings under `--json`).

Example: `tai hooks list --topic github`

```console
$ tai hooks list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--topic` `TEXT` | Filter to one topic. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai hooks register`

Register a hook from a HookParams JSON body.

Example: `tai hooks register --params '&#123;"name":"h1","topic":"github","tool":"notify"&#125;'`

```console
$ tai hooks register [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--params` `TEXT` | The full HookParams as a JSON object. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai hooks set-verifier`

Bind a webhook verifier to a topic so its deliveries are signature-verified.

Example: `tai hooks set-verifier github --verifier github_hmac`

```console
$ tai hooks set-verifier [OPTIONS] TOPIC
```

| Argument | Description |
| --- | --- |
| `TOPIC` | Hook topic. _(required)_ |

| Option | Description |
| --- | --- |
| `--verifier` `TEXT` | Registered webhook-verifier name. |
| `--config` `TEXT` | Verifier config as a JSON object. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
