## `tai plugins init`

Scaffold a descriptor-only plugin directory (yml, docs, licence, changelog).

`--kind connector` needs `--auth &#123;oauth,none&#125;`; `--kind mcp-server` takes no
`--auth`. The written tree parses as a plugin spec and its docs validate as-is;
edit the placeholders (`acme`, `example.invalid`, the icon) before publishing.

Example: `tai plugins init connector-acme --kind connector --auth oauth`

```console
$ tai plugins init [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | Plugin listing name (the 'name' half of namespace/name). _(required)_ |

| Option | Description |
| --- | --- |
| `--kind` `&lt;str&gt;` | Item kind to scaffold: connector or mcp-server. _(required)_ |
| `--auth` `&lt;str&gt;` | Connector auth mode (required for connector, forbidden for mcp-server). |
| `--dir` `&lt;path&gt;` | Target directory; defaults to ./NAME. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai plugins install`

Install a marketplace plugin by ref, optionally pinning a version.

`--mount` remaps a route-carrying item's base prefix; `--env KEY=VALUE` and
`--secret KEY` supply the install-time env the spec declares (an mcp entry's
`!ENV` markers or an oauth connector's client credentials, the secret
auto-marked); `--dry-run` previews the resolved routes, delivery, and required
env (exiting non-zero on any collision) without installing; and
`--accept-public-routes` is required when the plugin declares routes that
answer without authentication.

Before installing, the server's preview reports which required env is still
missing; an unresolved var not passed via `--env` fails the command before any
install is posted.

Example: `tai plugins install tai42/toolbox`

```console
$ tai plugins install [OPTIONS] {ref}
```

| Argument | Description |
| --- | --- |
| `ref` | Plugin ref 'namespace/name'. _(required)_ |

| Option | Description |
| --- | --- |
| `--version` `&lt;str&gt;` | Pin a specific version; omit for latest. |
| `--mount` `&lt;str&gt;` | Remap a route-carrying item's mount base as item=base (repeatable). |
| `--accept-public-routes` | Acknowledge routes that answer without authentication. _(default: `False`)_ |
| `--dry-run` | Show the resolved routes, delivery, and required env without installing. _(default: `False`)_ |
| `--env` `&lt;str&gt;` | Supply an install-time env value as KEY=VALUE (repeatable). |
| `--secret` `&lt;str&gt;` | Mark an env KEY secret (repeatable); the server auto-marks schema-known ones. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai plugins search`

Search the marketplace registry, optionally filtered by facets.

Example: `tai plugins search uuid --kind tool`

```console
$ tai plugins search [OPTIONS] [query]
```

| Argument | Description |
| --- | --- |
| `query` | Free-text search query; omit to browse all. _(optional)_ |

| Option | Description |
| --- | --- |
| `--kind` `&lt;str&gt;` | Filter by provides kind (tool, agent, ...). |
| `--category` `&lt;str&gt;` | Filter by category. |
| `--tag` `&lt;str&gt;` | Filter by tag (repeatable). |
| `--namespace` `&lt;str&gt;` | Filter by publisher namespace. |
| `--tier` `&lt;str&gt;` | Filter by trust tier. |
| `--contract` `&lt;str&gt;` | Filter by compatible contract version. |
| `--sort` `&lt;str&gt;` | Sort order (downloads, updated, name). |
| `--page` `&lt;int&gt;` | Result page (1-based). |
| `--page-size` `&lt;int&gt;` | Results per page. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai plugins update`

Update an installed plugin to a newer (or named) version.

`--env KEY=VALUE` and `--secret KEY` supply env a new version newly requires
(a fresh `!ENV` marker or connector credential); `--dry-run` previews the
target's delivery and required env. A required var still missing and not passed
via `--env` fails the command before any update is posted.

Example: `tai plugins update tai42/toolbox`

```console
$ tai plugins update [OPTIONS] {ref}
```

| Argument | Description |
| --- | --- |
| `ref` | Plugin ref 'namespace/name'. _(required)_ |

| Option | Description |
| --- | --- |
| `--version` `&lt;str&gt;` | Target version; omit for latest. |
| `--env` `&lt;str&gt;` | Supply an install-time env value as KEY=VALUE (repeatable). |
| `--secret` `&lt;str&gt;` | Mark an env KEY secret (repeatable); the server auto-marks schema-known ones. |
| `--dry-run` | Show the target's delivery and required env without updating. _(default: `False`)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai plugins upgrade`

Upgrade every installed plugin to its latest compatible version.

`--all` is required: the batch is deliberately explicit, and a single
plugin is upgraded with `tai plugins update REF` instead.

Example: `tai plugins upgrade --all`

```console
$ tai plugins upgrade [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--all` | Upgrade every installed plugin to its latest compatible version. _(default: `False`)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
