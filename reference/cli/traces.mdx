List and inspect run traces.

```console
$ tai traces [OPTIONS] COMMAND [ARGS]...
```

## `tai traces get`

Get one run's full trace, or download it as JSON with `--export`.

Example: `tai traces get trace_abc`

```console
$ tai traces get [OPTIONS] {trace_id}
```

| Argument | Description |
| --- | --- |
| `trace_id` | Trace id. _(required)_ |

| Option | Description |
| --- | --- |
| `--export` | Download the full trace as a JSON file instead. _(default: `False`)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai traces list`

List observability runs, or download the filtered list with `--export`.

Example: `tai traces list --status error --sort cost`

```console
$ tai traces list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--from` `&lt;str&gt;` | Range start: an ISO instant or a relative token (30d). |
| `--to` `&lt;str&gt;` | Range end: an ISO instant or a relative token. |
| `--status` `&lt;str&gt;` | Filter: 'error' or 'success'. |
| `--sort` `&lt;str&gt;` | Sort field: createdAt, cost, latencyMs, totalTokens. |
| `--dir` `&lt;str&gt;` | Sort direction: asc or desc. |
| `--page` `&lt;int&gt;` | Page number (1-based). |
| `--page-size` `&lt;int&gt;` | Rows per page. |
| `--export` | Download the filtered list instead of paging it. _(default: `False`)_ |
| `--format` `&lt;str&gt;` | Export format: csv or json (only with --export). _(default: `csv`)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
