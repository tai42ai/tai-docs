---
title: "tai traces"
description: "List and inspect run traces."
icon: "terminal"
---

List and inspect run traces.

```console
$ tai traces [OPTIONS] COMMAND [ARGS]...
```

## `tai traces capabilities`

Show what the monitoring backend serves: the page maximum, the sorts and the sort/filter combinations.

Example: `tai traces capabilities`

```console
$ tai traces capabilities [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai traces get`

Get one run's full trace, or download it as JSON with `--export`.

Example: `tai traces get trace_abc`

```console
$ tai traces get [OPTIONS] {trace_id}
```

| Argument | Description |
| --- | --- |
| `trace_id` | Trace id. _(required)_ |

| Option | Description |
| --- | --- |
| `--export` | Download the full trace as a JSON file instead. _(default: `False`)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai traces list`

List observability runs, or download the filtered list with `--export`.

Example: `tai traces list --status error --sort cost`

```console
$ tai traces list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--from` `&lt;str&gt;` | Range start: an ISO instant or a relative token (30d). |
| `--to` `&lt;str&gt;` | Range end: an ISO instant or a relative token. |
| `--status` `&lt;str&gt;` | Filter: 'error' or 'success'. |
| `--sort` `&lt;str&gt;` | Sort field: createdAt, cost, latencyMs, totalTokens. |
| `--dir` `&lt;str&gt;` | Sort direction: asc or desc. |
| `--page` `&lt;int&gt;` | Page number (1-based). |
| `--page-size` `&lt;int&gt;` | Rows per page. |
| `--export` | Download the filtered list instead of paging it. _(default: `False`)_ |
| `--format` `&lt;str&gt;` | Export format: csv or json (only with --export). _(default: `csv`)_ |
| `--user` `&lt;str&gt;` | Filter: runs stamped with this user identity. |
| `--session` `&lt;str&gt;` | Filter: runs stamped with this session identity. |
| `--version` `&lt;str&gt;` | Filter: runs stamped with this trace version dimension. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai traces outline`

Get one run's span tree: every span with its parent, kind, status and metadata, without input/output.

Example: `tai traces outline trace_abc`

```console
$ tai traces outline [OPTIONS] {trace_id}
```

| Argument | Description |
| --- | --- |
| `trace_id` | Trace id. _(required)_ |

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai traces value`

Read one span field's value with every record reference resolved.

Example: `tai traces value trace_abc span_1 --field output --pointer /outputs/n`

```console
$ tai traces value [OPTIONS] {trace_id} {span_id}
```

| Argument | Description |
| --- | --- |
| `trace_id` | Trace id. _(required)_ |
| `span_id` | Span (observation) id. _(required)_ |

| Option | Description |
| --- | --- |
| `--field` `&lt;str&gt;` | The span field: input or output. _(default: `input`)_ |
| `--pointer` `&lt;str&gt;` | RFC 6901 JSON pointer into the field (e.g. /messages/0). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
