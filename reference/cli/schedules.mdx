Manage scheduled jobs.

```console
$ tai schedules [OPTIONS] COMMAND [ARGS]...
```

## `tai schedules add`

Create a schedule that periodically runs a tool.

Example: `tai schedules add report --schedule-kw cron='0 9 * * *'`

```console
$ tai schedules add [OPTIONS] {tool_name}
```

| Argument | Description |
| --- | --- |
| `tool_name` | The tool to run on a schedule. _(required)_ |

| Option | Description |
| --- | --- |
| `--tool-kwargs` `&lt;str&gt;` | Tool arguments as a JSON object. |
| `--tool-kw` `&lt;str&gt;` | A key=value tool argument (repeatable). |
| `--schedule-kwargs` `&lt;str&gt;` | Schedule cadence params as JSON. |
| `--schedule-kw` `&lt;str&gt;` | A key=value schedule param (repeatable). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai schedules delete`

```console
$ tai schedules delete [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | Schedule name. _(required)_ |

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
