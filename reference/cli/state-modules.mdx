Manage platform state-module documents.

```console
$ tai state-modules [OPTIONS] COMMAND [ARGS]...
```

## `tai state-modules delete`

Delete a state-module document (refused while it is mounted).

```console
$ tai state-modules delete [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | The module name. _(required)_ |

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai state-modules get`

Show one state-module document.

```console
$ tai state-modules get [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | The module name. _(required)_ |

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai state-modules list`

List every platform state-module document.

```console
$ tai state-modules list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai state-modules put`

Create or replace a state-module document.

```console
$ tai state-modules put [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | The module name. _(required)_ |

| Option | Description |
| --- | --- |
| `--data` `&lt;str&gt;` | The module document JSON. |
| `--file` `&lt;path&gt;` | A file holding the module document JSON. |
| `--replace` | Overwrite an existing module of this name. _(default: `False`)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
