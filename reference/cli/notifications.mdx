Read and send internal notifications.

```console
$ tai notifications [OPTIONS] COMMAND [ARGS]...
```

## `tai notifications list`

List the internal notifications, newest-first.

Example: `tai notifications list`

```console
$ tai notifications list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai notifications notify`

Send a human a one-way, fire-and-forget notification.

`--media`, `--template` and `--options` are JSON strings (the nested shapes have
no flat-flag form). The CLI checks only their shape before the request — a list of
`MediaItem` for `--media`, `list[str]` for `--options`, a `ChannelTemplate` for
`--template` — so a mis-shaped value raises loudly here; the contract's richer rules
(caps, non-blank, exclusivity) are enforced by the server.

Example: `tai notifications notify "Deploy finished" --channel telegram`

```console
$ tai notifications notify [OPTIONS] {message}
```

| Argument | Description |
| --- | --- |
| `message` | The notification text shown to the human. _(required)_ |

| Option | Description |
| --- | --- |
| `--channel` `&lt;str&gt;` | Named channel to send on; omit to record to the internal sink. |
| `--recipient` `&lt;str&gt;` | Optional per-call address (chat id, phone number, ...). |
| `--media` `&lt;str&gt;` | JSON array of display-media items sent WITH the message, e.g. '[&#123;"kind":"image","url":"https://…"&#125;]'. |
| `--template` `&lt;str&gt;` | JSON object for an out-of-window template send, e.g. '&#123;"name":"status_update","language":"en_US"&#125;'. |
| `--options` `&lt;str&gt;` | JSON array of tappable options, e.g. '["Item A","Item B"]'. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
