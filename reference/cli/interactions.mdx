List, stream and answer pending interactions.

```console
$ tai interactions [OPTIONS] COMMAND [ARGS]...
```

## `tai interactions answer`

Answer a pending interaction. The value is validated server-side.

Example: `tai interactions answer i_123 --answer '"yes"'`

```console
$ tai interactions answer [OPTIONS] {interaction_id}
```

| Argument | Description |
| --- | --- |
| `interaction_id` | Interaction id. _(required)_ |

| Option | Description |
| --- | --- |
| `--answer` `&lt;str&gt;` | The answer value as JSON (a string, bool, object, ...). _(required)_ |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai interactions list`

Print one page of pending interactions.

Example: `tai interactions list --page 1 --page-size 50`

```console
$ tai interactions list [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--page` `&lt;int&gt;` | Page number (1-based). |
| `--page-size` `&lt;int&gt;` | Items per page (capped at 200). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai interactions stream`

Tail the interactions inbox live (add/answered/removed events).

Example: `tai interactions stream`

```console
$ tai interactions stream [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
