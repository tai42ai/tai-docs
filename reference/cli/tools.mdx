Inspect and run registered tools.

```console
$ tai tools [OPTIONS] COMMAND [ARGS]...
```

## `tai tools apply`

Set a tool's full list of extension combos (lossless multi-combo write).

Each `--combo` is one combo, written as a JSON array of extension elements;
repeat it to author several combos at once. An element is a bare extension
name or a `&#123;"name", "config"&#125;` object binding author config, so per-element
config (e.g. an `output_schema` combo's schema) round-trips losslessly.
Passing no `--combo` clears every combo.

Example: `tai tools apply my_tool --combo '["chain","batch"]' --combo '["chain"]'`

```console
$ tai tools apply [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | Tool name. _(required)_ |

| Option | Description |
| --- | --- |
| `--combo` `&lt;str&gt;` | One extension combo as a JSON array of elements (repeatable). Each element is an extension name ('"chain"') or a &#123;"name","config"&#125; object binding config to it (e.g. '[&#123;"name":"output_schema","config":&#123;"schema":&#123;"type":"object"&#125;&#125;&#125;]'). Passing no --combo clears the tool's extensions. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai tools reload`

Re-register one app tool from its stored definition, fanning out to the fleet.

Example: `tai tools reload flow my_flow`

```console
$ tai tools reload [OPTIONS] {kind} {name}
```

| Argument | Description |
| --- | --- |
| `kind` | Tool kind (e.g. "flow"). _(required)_ |
| `name` | Tool name. _(required)_ |

| Option | Description |
| --- | --- |
| `--target` `&lt;str&gt;` | A worker to restrict the fan-out to (repeatable). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai tools run`

Run a registered tool synchronously and print its result.

Example: `tai tools run add --kw a=1 --kw b=2`

```console
$ tai tools run [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | Tool name. _(required)_ |

| Option | Description |
| --- | --- |
| `--kwargs` `&lt;str&gt;` | Tool arguments as a JSON object. |
| `--kwargs-file` `&lt;str&gt;` | Read the tool arguments JSON object from a file, or from stdin when the path is '-', instead of putting a secret on the command line (a value on argv leaks via ps and shell history). Mutually exclusive with --kwargs; --kw pairs still override its keys. |
| `--kw` `&lt;str&gt;` | A key=value tool argument (repeatable; value parsed as JSON). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
