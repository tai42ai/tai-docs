Manage preset tools and their versions.

```console
$ tai presets [OPTIONS] COMMAND [ARGS]...
```

## `tai presets create`

Create a versioned preset (or an authored agent, when the base tool is an agent).

Example: `tai presets create greet --base-tool echo --description 'Greet a user' --kwargs '&#123;"prefix":"hi"&#125;'`

```console
$ tai presets create [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | Preset name. _(required)_ |

| Option | Description |
| --- | --- |
| `--base-tool` `&lt;str&gt;` | The registered non-preset tool the preset wraps. _(required)_ |
| `--description` `&lt;str&gt;` | The preset's LLM-facing description (required, non-empty). _(required)_ |
| `--kwargs` `&lt;str&gt;` | Baked fixed kwargs as a JSON object. |
| `--kwargs-file` `&lt;str&gt;` | Read the fixed kwargs JSON object from a file, or from stdin when the path is '-', instead of putting a secret on the command line (a value on argv leaks via ps and shell history). Mutually exclusive with --kwargs. |
| `--extensions` `&lt;str&gt;` | Extension combos as a JSON array of combos. Each combo is a non-empty array of elements, and an element is an extension name ('"chain"') or a &#123;"name","config"&#125; object binding config to it (e.g. '[[&#123;"name":"output_schema","config":&#123;"schema":&#123;"type":"object"&#125;&#125;&#125;]]'). |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

## `tai presets save-version`

Save a new preset version. Omitted fields carry forward; `--extensions '[]'`
sends the explicit clear sentinel.

Example: `tai presets save-version my_preset --kwargs '&#123;"n":2&#125;'`

```console
$ tai presets save-version [OPTIONS] {name}
```

| Argument | Description |
| --- | --- |
| `name` | Preset name. _(required)_ |

| Option | Description |
| --- | --- |
| `--kwargs` `&lt;str&gt;` | New fixed kwargs (JSON object); omit to carry forward. |
| `--kwargs-file` `&lt;str&gt;` | Read the fixed kwargs JSON object from a file, or from stdin when the path is '-', instead of putting a secret on the command line (a value on argv leaks via ps and shell history). Mutually exclusive with --kwargs. |
| `--description` `&lt;str&gt;` | New description (non-empty); omit to carry the active one forward. |
| `--extensions` `&lt;str&gt;` | Extension combos as a JSON array of combos. Each combo is a non-empty array of elements, and an element is an extension name ('"chain"') or a &#123;"name","config"&#125; object binding config to it (e.g. '[[&#123;"name":"output_schema","config":&#123;"schema":&#123;"type":"object"&#125;&#125;&#125;]]'). '[]' clears them. |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |

| `tags...` | The tags to set; none clears them to []. _(optional)_ |

| --- | --- |
