Inspect the sandbox provider's identity and resolved policy.

```console
$ tai sandbox [OPTIONS] COMMAND [ARGS]...
```

## `tai sandbox info`

Show the registered sandbox provider's identity and resolved policy (or the empty state).

Example: `tai sandbox info`

```console
$ tai sandbox info [OPTIONS]
```

| Option | Description |
| --- | --- |
| `--json` / `--no-json` | Emit raw JSON instead of human tables. |
