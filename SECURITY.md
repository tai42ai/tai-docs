# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues.

Instead, email **oss@tai42.ai** with:

- a description of the issue and its impact,
- steps to reproduce (a proof-of-concept if possible),
- the affected page(s) or script(s).

We aim to acknowledge reports within a few business days and will keep you
updated on remediation. Please give us a reasonable opportunity to address the
issue before any public disclosure.

## Supported Versions

This repository is the source of a continuously deployed site; it publishes no
released versions. Fixes land on `main` and reach the live site with the next
deploy.
