## Connect the server outward

To connect the server to the apps your team already uses — Gmail, Calendar,
Drive, Jira, Confluence, and more — install a
[connector](/concepts/connectors) from the [Plugins section](/plugins). The
connector model is [Connectors](/concepts/connectors); the end-to-end setup is
[Connect an OAuth provider](/guides/connect-an-oauth-provider).
